# Tribute Page — OIBSIP Web Development Internship (Level 2, Task 2)

## Objective
A tribute page dedicated to Rani Lakshmibai, the Warrior Queen of Jhansi, built using HTML5 and CSS3 to practice content-driven page design, typography, and layout structuring.

## Tech Stack
- HTML5
- CSS3 (responsive layout, Google Fonts)

## Features
- Page title with the subject's name and a one-line tagline
- A prominent image sourced from Wikimedia Commons
- A 4-paragraph original biography section covering her early life, marriage, role in the Revolt of 1857, and legacy
- A timeline section listing key milestones from 1828 to 1858
- A styled quote block featuring her famous declaration, with translation
- Two distinct background colours used across sections (maroon hero/footer, cream and dark sections)
- Two font styles used — Playfair Display (serif) for headings, Poppins (sans-serif) for body text
- Fully responsive layout via CSS media queries

## How to Run
1. Clone or download this folder
2. Open `index.html` in any web browser
3. No build steps or dependencies required

# To-Do Web App — OIBSIP Web Development Internship (Level 2, Task 3)

## Objective
An interactive to-do list application that allows users to add, complete, edit, and delete tasks, organised into Pending and Completed lists, with persistence across page refreshes.

## Tech Stack
- HTML5
- CSS3 (responsive grid layout)
- JavaScript (Vanilla — DOM manipulation, localStorage)

## Features
- Input field + "Add Task" button to create new tasks
- New tasks appear immediately in the Pending list
- "Mark Complete" checkbox moves a task to the Completed list
- Inline Edit — modify task text without losing its data
- Delete button permanently removes a task from either list
- Live task count indicators ("X pending", "Y completed")
- Timestamp shown on each task — when it was added and/or completed
- Tasks persist across page refreshes using `localStorage`
- Friendly empty-state messages when a list has no items
- Fully responsive layout (single column on mobile)

## How to Run
1. Clone or download this folder
2. Open `index.html` in any web browser
3. No build steps or dependencies required — data is stored locally in your browser
